# Riftbound Wishlist Website

Static landing page for the Riftbound Wishlist Chrome extension.

## Files

- `index.html` — page content
- `styles.css` — styling

## Local preview

Open `index.html` directly in a browser, or run a local server:

```powershell
python3.12 -m http.server 8000
```

Then visit:

`http://localhost:8000`

## Publishing with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and `styles.css`.
3. Open the repository's Settings.
4. Open Pages.
5. Set the source to the `main` branch and `/ (root)`.
6. GitHub will provide a public URL similar to:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

That URL can be used as the product URL while the Chrome extension is still in development.
