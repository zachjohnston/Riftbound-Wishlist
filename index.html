CHROME EXTENSION · RIFTBOUND

Keep track of the cards you want.

Riftbound Wishlist is a lightweight Chrome extension for searching Riftbound cards, building a personal wishlist, importing decklists, and spotting wishlist cards while browsing supported websites.

FEATURES

Built around the way players browse cards.

01

Card search

Search the Riftbound card library and add cards directly to your wishlist.

02

Wishlist management

Track the cards and quantities you want in a compact extension popup.

03

Decklist import

Import a decklist and use its cards as the starting point for a wishlist.

04

Page detection

When a supported webpage contains a card on your wishlist, the extension can highlight it and notify you.

HOW IT WORKS

Simple by design.

1

Search or import

Find individual cards or import an existing decklist.

2

Set quantities

Choose how many copies of each card you want.

3

Browse normally

The extension checks supported webpages for cards on your wishlist.

About the project

Riftbound Wishlist is an independent fan-made project. It is intended to provide convenient card discovery and wishlist functionality without changing or automating Riftbound gameplay.

Riftbound and related intellectual property are owned by Riot Games and its respective licensors. This project is not endorsed by or affiliated with Riot Games.
